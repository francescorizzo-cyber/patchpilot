Community patch library

Patches for Zoom pedals made and shared by PatchPilot users: search by song, artist or pedal, look at the effects and open the file in PatchPilot. All patches are free for everyone (CC0).

🔜 The library opens with the next version of PatchPilot. In the program and in the app you will find Patch → Share in the library: one click fills in the form, an automatic check verifies the patch, and once approved it appears here.

Share a patch

How it works

  1. Share: in PatchPilot, Patch page → Condividi nella libreria… (share in the library). Choose the patch, write your name and, if you like, song, artist, genre and notes.
  2. Check: the form on GitHub opens already filled in. An automatic check verifies the patch within a minute. No GitHub account? Send it by email from the same window.
  3. Library: once approved the patch appears on this page and in the public repository, free for everyone.
  4. Use: download the file and open it in PatchPilot with Importa…: you get the sound sheet with effects and values. Sending it straight to the pedal will come after the tests on real pedals.

Only the patch is shared (which effects and with which values), never Zoom's effect files. Patches are CC0: anyone can use and change them.
