Libreria di patch della comunità

Patch per i pedali Zoom fatte e condivise da chi usa PatchPilot: cerca per brano, artista o pedale, guarda gli effetti e apri il file in PatchPilot. Tutte le patch sono libere per tutti (CC0).

📚 La libreria è aperta, da PatchPilot 0.9. Nel programma per computer trovi Patch → Condividi nella libreria: un clic compila il modulo, un controllo automatico verifica la patch e, appena approvata, compare qui.

Condividi una patch

Come funziona

  1. Condividi: in PatchPilot, pagina Patch → Condividi nella libreria…. Scegli la patch, scrivi il tuo nome e, se vuoi, brano, artista, genere e note.
  2. Controllo: si apre il modulo su GitHub già compilato. Un controllo automatico verifica la patch in un minuto. Non hai un account GitHub? Mandala per email dalla stessa finestra.
  3. Libreria: appena approvata la patch compare in questa pagina e nel repository pubblico, libera per tutti.
  4. Usala: scarica il file e aprilo in PatchPilot con Importa…: vedi la scheda suono con effetti e valori. L'invio diretto al pedale arriverà dopo le prove sui pedali reali.

Si condivide solo la patch (quali effetti e con quali valori), mai i file degli effetti Zoom. Le patch sono CC0: chiunque può usarle e modificarle.
